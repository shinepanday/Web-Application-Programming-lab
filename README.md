This repository contains a collection of 6 labs that cover both frontend and backend development, starting from basics and gradually moving to full-stack concepts.

**LAB1 – Portfolio with Calendar**
A simple personal portfolio website built using HTML, CSS, and JavaScript. It includes a calendar feature to demonstrate basic DOM manipulation and UI design.

**LAB2 – Introduction to JavaScript**
Covers core JavaScript concepts including `var`, `let`, `const`, functions, arrow functions, objects, and modern features like `map`, `filter`, and spread operators.

**LAB3 – Login & Register Form (React)**
A React-based authentication UI with login and registration forms. It uses custom input components and state management to handle user input and form behavior.

**LAB4 – Todo CRUD App (React)**
A Todo application built with React that demonstrates Create, Read, Update, and Delete operations using state manipulation.

**LAB5 – Backend Authentication (FastAPI)**
Implements login and registration on the backend using FastAPI. Includes proper project structure with controllers, database connection, models, migrations, and API routes.

**LAB6 – User-Based Todo Backend (FastAPI)**
Extends the backend by linking todos to authenticated users. Uses ORM and migrations to manage data and ensures each user only accesses their own todos.

Overall, this repo shows a step-by-step progression from basic frontend to full-stack development with authentication and database integration.
